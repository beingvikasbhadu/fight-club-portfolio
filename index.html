WAL ENGINE

Production-grade Distributed Write-Ahead Log engine built in core Java. Implements crash-safety from the ground up — group commit batching, binary serialization with CRC32 corruption detection, fsync durability, checkpoint-based crash recovery, log compaction, and real-time gRPC streaming replication between primary and replica nodes.
